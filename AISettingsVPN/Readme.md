# Руководство по доступу к Google Gemini из РФ
Единственный автор: ***Fizr***

## 📋 Оглавление:

1. Настройка через браузер (Лучший вариант для ПК)
2. Системная настройка на компьютере
3. Настройка на телефоне (Android / iOS)
4. Проверка подключения
## 🌐 1. Настройка через браузер (Лучший вариант для ПК)
Этот метод активирует безопасный DNS исключительно для веб-серфинга. Параметры других программ, онлайн-игр и ваш пинг останутся без изменений.

### 🔹 Chrome / Edge / Opera / Яндекс.Браузер
Перейдите в «Настройки» вашего браузера, далее в раздел «Безопасность».
Отыщите строку «Использовать безопасный DNS-сервер».
Активируйте эту функцию и укажите вариант «С другим поставщиком».
В открывшемся поле пропишите адрес:

https://xbox-dns.ru/dns-query
### 🔹 Firefox
Зайдите в меню «Настройки», затем откройте «Приватность и Защита».
Прокрутите страницу до блока «DNS через HTTPS».
Установите режим «Максимальная защита», а в пункте выбора провайдера кликните «По выбору».
В появившемся окне введите:

https://xbox-dns.ru/dns-query

## 💻 2. Системная настройка на компьютере
### 🔹 Windows 11 (Рекомендуется DoH)
Запустите «Параметры» системы, перейдите в «Сеть и Интернет», выбрав ваше подключение («Wi-Fi» либо «Ethernet»).
Кликните на «Свойства оборудования».
В блоке назначения DNS-сервера нажмите кнопку «Изменить».
Выберите ручной ввод, активируйте протокол IPv4 и пропишите адреса: 111.88.96.50 и 111.88.96.51.
В поле «Предпочтительное шифрование DNS» укажите «Только шифрование (DNS через HTTPS)». Ниже введите:

https://xbox-dns.ru/dns-query
### 🔹 Windows 10 и более старые версии
Зайдите в «Панель управления», далее в «Центр управления сетями и общим доступом».
Кликните по текущему интернет-подключению (например, «Wi-Fi»).
В появившемся меню выберите «Свойства».
Найдите строку «IP версии 4 (TCP/IPv4)» и снова нажмите «Свойства».
Активируйте пункт «Использовать следующие адреса DNS-серверов» и укажите: 111.88.96.50 и 111.88.96.51.
Сохраните изменения кнопкой «ОК».

## 📱 3. Настройка на телефоне (Android / iOS)
### 🔹 Android (версия 9 и новее)
Откройте общие «Настройки» смартфона, перейдите в раздел «Сеть и Интернет», затем найдите «Частный DNS-сервер».
Выберите пункт для ввода имени хоста провайдера.
Напишите
xbox-dns.ruи подтвердите сохранение.
### 🔹 iOS (версия 14 и новее)
Наиболее удобный метод — скачивание профиля конфигурации, который сам пропишет нужные данные для шифрованного DNS.

Обязательно: выполняйте этот шаг через браузер Safari.
Перейдите по ссылке для загрузки нужного файла: xbox-dns.ru/ios/xbox-dns.mobileconfig
Разрешите скачивание. Затем в основных «Настройках» айфона появится пункт «Профиль загружен».
Нажмите на него и выберите «Установить» в правом верхнем углу, подтверждая системные запросы.

## 🛠 4. Проверка подключения
Чтобы убедиться, что всё настроено верно, просто нажмите сюда: https://xbox-dns.ru/test
Если сервис выдает ошибку подключения, выполните перезагрузку устройства (компьютера или смартфона) — как правило, это сразу исправляет ситуацию.
