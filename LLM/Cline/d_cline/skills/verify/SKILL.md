# /verify — Верификация перед завершением

Цель: обязательная финальная проверка (сборка + тесты + линтер + diff) ПЕРЕД тем, как объявить задачу готовой. Закрывает типичную ошибку «я всё сделал» без запуска кода.

## Что сделать по порядку
1. **Сборка**: запустить build-команду проекта (найти в package.json / Makefile / CI). Готово: exit code = 0.
2. **Тесты**: запустить полный тестовый прогон. Готово: все зелёные, нет fail/skip без причины.
3. **Линтер/типы** (если есть в проекте): линтер + type-check. Готово: нет ошибок (warnings — перечислить).
4. **Diff-ревью**: просмотреть `git diff` всех изменений. Проверить:
   - нет мусора (отладочные print, закомментированный код, TODO без причины),
   - изменения соответствуют заявленной задаче,
   - не затронуто то, что не нужно было трогать.

## Правила
- Если любой шаг упал — НЕ объявлять готово. Вернуться к исправлению (Error Handling Rule: сначала читать ошибку).
- Не повторять упавшую команду > 2 раз без смены подхода (Anti-Loop Rule).
- Если команда запуска неизвестна — найти её в конфиге/CI, не гадать.

## Финальный вывод
Отчёт пользователю: сборка ✅/❌, тесты N passed / M failed, линтер чист/список warnings, diff — краткое резюме изменений. Только после этого задача считается завершённой (Definition of Done).
